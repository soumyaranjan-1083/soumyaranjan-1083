### 👋 About this account

I'm **Soumyaranjan**, a Data Engineer at **Accenture**. My day job is pipelines and data. My nights go to the thing I'm actually curious about: **design and building products**.

This GitHub account is a dedicated lab for projects that I create **together with AI**. Web apps, mobile apps, desktop apps and developer tools. I steer the idea, the design and the decisions; AI helps me write, refactor and ship much faster than I could alone.

> *Everything here is honest about how it was made: AI-assisted, human-directed.*

### 🧭 How I build with AI

1. **Idea first.** I define the problem and the feel of the product before touching code.
2. **Prompt like a product owner.** Clear specs, closed lists, acceptance tests.
3. **Review, don't just accept.** I read what AI writes, test it on a real phone and push back.
4. **Ship small, iterate fast.** Real users (starting with me) decide what's next.
5. **Right tool for the job.** Claude for planning, prompts and debugging; Copilot inside VS Code for implementation; Gemini for live voice features in my apps.
